# 📊 Pimentones La Cajita · Backoffice Frontend (Panel de Control)

Aplicación web administrativa para la gestión operativa, comercial y logística de Pimentones La Cajita.

## 🛠️ Módulos de Gestión
* **Dashboard:** KPIs en vivo (ventas totales, ingresos de hoy, pedidos pendientes, ticket promedio).
* **Gestión de Pedidos:** Aprobación, actualización de estados de despacho y números de guía.
* **Inventario & Kardex:** Control de lotes de producción de conservas, mermas y ajustes de stock.
* **Catálogo & Precios:** Edición de productos, precios y disponibilidad en tienda.
* **Zonas & Tarifas:** Configuración de costos de flete (Bogotá Local, Sabana, Nacional).
* **Cupones de Descuento:** Creación de promociones porcentuales o de monto fijo.
* **Bandeja de Mensajes:** Consultas de clientes y lista de suscriptores al boletín.
* **Usuarios & Seguridad:** Control de acceso basado en roles (Superadmin, Operador) y auditoría.

## 🚀 Inicio Rápido
``bash
npm install
npm run dev
``
Disponible en: [http://localhost:3001/admin](http://localhost:3001/admin) (o en [http://localhost:3000/admin](http://localhost:3000/admin) vía Storefront).
